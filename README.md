# CACTIPVP

CACTIPVP is a client-side PvP enhancement mod designed to complement the popular Cactus quality-of-life mod (the QoL utility, not the one that adds cactus armor and tools). It adds a few essential, customizable PvP features to improve your combat experience.

You can find the official downloads here: https://modrinth.com/mod/cactipvp

## Current Modules

* **Low Shield:** Lowers the shield overlay so it does not block your view. You can customize the exact positions for both your main hand and offhand.
* **Low Fire:** Lowers the fire effect on your screen when you are burning. Includes a customizable Y-offset adjustment.
* **Particle Control:** Lets you disable all particles, toggle specific ones, or multiply them for better visual feedback.
* **Combat Hitboxes:** Shows cleaner, simpler hitboxes than vanilla. They also change color dynamically depending on the current combat situation.
